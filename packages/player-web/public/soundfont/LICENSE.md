# Tome piano soundfont

Five synthesised samples (C2–C6, Opus in OGG, ~70 kB total), generated by `tools/gen_piano.py`
in this repository. Not a recording of any instrument, so there are no sample-library licence
terms attached: the files are part of Tome and ship under the same licence as the player.

The player pitch-shifts each sample up to ±6 semitones to cover the keyboard. That is audibly
a compromise above about C6, which is why the range offered to authors stops there.
