# Saludos — Hello and Goodbye

Spanish greetings change with the time of day. Listen to each one before you read it — your ear should meet the word before your eye does.

:::widget type="flashcards" id="saludos-cards"
spaced: true
shuffle: false
cards:

    back: Hello — any time of day
  - front: { text: "**Buenos días**", audio: assets/audio/buenos-dias.mp3 }
    back: Good morning — until lunch, around 2 pm
  - front: { text: "**Buenas tardes**", audio: assets/audio/buenas-tardes.mp3 }
    back: Good afternoon — from lunch until dark
  - front: { text: "**Buenas noches**", audio: assets/audio/buenas-noches.mp3 }
    back: Good evening *and* good night
  - front: { text: "**Adiós**", audio: assets/audio/adios.mp3 }
    back: Goodbye
  - front: { text: "**Hasta luego**", audio: assets/audio/hasta-luego.mp3 }
    back: See you later — the everyday goodbye
:::

:::note title="Why días is plural"
Spanish wishes you *good days*, not a good day. Nobody knows quite why; just enjoy the generosity.
:::

## Which one did you hear?

:::widget type="multiple-choice" id="saludos-hear-1"
audio:
  src: assets/audio/buenas-tardes.mp3
  transcript: Buenas tardes.
prompt: Listen. Which greeting is it?
options:
  - text: Buenos días
    explanation: '*Buenos días* starts with *buenos* and ends in *días*. Listen again for the second word, which is not *días*.'
  - text: Buenas tardes
    correct: true
  - text: Buenas noches
    explanation: '*Buenas noches* ends in *noches*, with an *o* and a *ch*. Listen again to the second word.'
hint: 'Listen to the second word. Is it *días*, *tardes* or *noches*?'
explanation: '*Tardes* means afternoon. Spaniards say *buenas tardes* from lunch, around 2 pm, until it gets dark. Notice *buenas* rather than *buenos*: *tarde* is feminine, while *día* is masculine, hence *buenos días*.'
:::

:::

## Write what you hear

Your first dictation. Accents matter in Spanish — *día* with an accent is a day; without it, it is nothing. Type them if you can (hold the key on a phone keyboard).

:::widget type="dictation" id="saludos-dictation"
audio:
  src: assets/audio/buenos-dias.mp3
  transcript: Buenos días.
  playLimit: 3
answer: Buenos días
ignoreAccents: true
hint: Two words. The second one is plural.
explanation: '*Buenos días* — plural, literally *good days*. The accent on the *í* of *días* marks the stressed syllable: DÍ-as, two syllables, not one. This widget ignores missing accents, but it is worth writing them, because in Spanish an accent can change the meaning of a word.'
:::
